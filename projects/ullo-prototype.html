Prototype de Jeu - Stage

Prototype développé lors d'un stage chez Ullo — jeu exploitant le neurofeedback en VR.

C#UnityVR
VR Prototype — Demo

Ce projet a été réalisé sur Unity durant mon stage de 5 semaines au sein de l'entreprise Ullo. C'est un jeu exploitant le neurofeedback (modulation de l'activité cérébrale) en combinant un Oculus Quest, un bandeau Muse pour l'activité cérébrale, et une montre connectée pour le rythme respiratoire.

Fonctionnalités Implémentées

01 Gameplay basé sur le Neurofeedback

La capacité de voler est directement liée aux fréquences cérébrales du joueur.

02 Création d'Environnement

Mise en place du monde de jeu avec terrain, ciel personnalisable et plateformes.

03 Interaction Dynamique

Les objets du jeu changent de position et de forme en fonction des données de neurofeedback.

04 Système de Collectibles

Intégration de pièces à récupérer avec un compteur de score.

05 Interface Utilisateur

Création d'une UI permettant de configurer différents paramètres du jeu.

This project was developed in Unity during my 5-week internship at Ullo. It uses neurofeedback (brain activity modulation) combining an Oculus Quest, a Muse headband, and a smartwatch.

Implemented Features

01 Neurofeedback-Based Gameplay

The ability to fly is directly linked to the player's brain frequencies.

02 Environment Creation

Game world with terrain, customizable sky, and platforms.

03 Dynamic Interaction

Game objects change position and shape based on neurofeedback data.

04 Collectible System

Coins with a score counter.

05 User Interface

UI to configure various game settings.
